# 股价到达通知 — 技术设计文档

## 1. 功能概述

做T管理中的网格档位触发后，通过微信实时通知用户。当股价**到达**未触发档位价格时，自动推送微信消息，提醒用户执行对应买卖操作。

## 2. 通知渠道

选用 **Server酱（ServerChan）**，接入方式：

```
POST https://sctapi.ftqq.com/{SendKey}.send
Content-Type: application/json

{
  "title": "📈 卖出点位到达 · 红日药业",
  "desp": "卖出第2档 · ¥4.63\n当前价 ¥4.65 · 已触及\n建议按计划卖出 100 股"
}
```

- 免费额度：每天 5 条，档位触发提醒场景足够
- 用户自行注册获取 SendKey，填入系统配置即可

## 3. 核心逻辑

```
每 1 分钟轮询一次（仅交易日 9:30-15:00）：

1. 查询 t_stock_config 中所有 active=1 的做T规则
2. 通过 StockPriceUtil.fetchBatch() 批量获取实时行情
3. 对每条规则，查询其下所有 triggered=0 的档位：
   - 卖出档位（direction=2）：currentPrice >= levelPrice → 触发
   - 买入档位（direction=1）：currentPrice <= levelPrice → 触发
   遍历所有未触发档位，避免跳空高开/低开漏掉跨过的中间档位
4. 对触发档位，查询 t_stock_price_alert 中当天是否已有通知：
   - 有 → 跳过
   - 无 → 调用 Server酱发送微信通知 + 写入告警记录
5. 用户完成操作后档位标记为 triggered=1，自然退出监控
```


## 4. 通知配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| sendKey | 空 | Server酱 SendKey，为空则不推送 |
| enable | false | 通知总开关 |

> 存储方式：`sys_config` 表 key-value 形式，预留扩展能力（后续"可用资金"等全局配置也放此表）。

## 5. 数据库设计

### 5.1 通知告警表

```sql
CREATE TABLE t_stock_price_alert (
  id            BIGINT        NOT NULL COMMENT '主键',
  config_id     BIGINT        NOT NULL COMMENT '关联 t_stock_config.id',
  stock_code    VARCHAR(16)   NOT NULL COMMENT '股票代码',
  stock_name    VARCHAR(64)   DEFAULT NULL COMMENT '股票名称',
  direction     TINYINT       NOT NULL COMMENT '买卖方向 1-买入 2-卖出',
  level_no      INT           NOT NULL COMMENT '档位编号',
  trigger_price DECIMAL(12,4) NOT NULL COMMENT '目标触发价',
  current_price DECIMAL(12,4) NOT NULL COMMENT '通知时的现价',
  send_key      VARCHAR(128)  DEFAULT NULL COMMENT '使用的SendKey',
  create_time   DATETIME      NOT NULL COMMENT '通知时间',
  PRIMARY KEY (id),
  INDEX idx_config_level (config_id, direction, level_no, create_time)
) COMMENT '股价到达告警记录';
```


### 5.2 系统配置表

```sql
CREATE TABLE sys_config (
  id          BIGINT      NOT NULL COMMENT '主键',
  config_key  VARCHAR(64) NOT NULL COMMENT '配置键',
  config_value VARCHAR(512) DEFAULT NULL COMMENT '配置值',
  remark      VARCHAR(128) DEFAULT NULL COMMENT '说明',
  create_time DATETIME    NOT NULL,
  update_time DATETIME    NOT NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uk_config_key (config_key)
) COMMENT '系统配置表';
```

预置数据：

| config_key | config_value | remark |
|------------|-------------|--------|
| notify.send_key | '' | Server酱 SendKey |
| notify.enable | 'false' | 通知开关 |

### 6.2 核心类设计

#### StockPriceMonitorTask

```java
@Component
public class StockPriceMonitorTask {

    @Autowired
    private StockTradeConfigMapper configMapper;
    @Autowired
    private StockTradeOperationMapper operationMapper;
    @Autowired
    private StockPriceAlertMapper alertMapper;
    @Autowired
    private WeChatNotifyService notifyService;

    // 每1分钟执行，仅交易日9:30-11:30  13:00-15:00
    public void monitor() {
        // 1. 检查通知开关，关闭则跳过
        // 2. 查询 active=1 的做T规则
        // 3. 提取所有 stockCode，调用 StockPriceUtil.fetchBatch()
        // 4. 遍历每个规则，查询 triggered=0 的档位
        // 5. 判断当前价是否触及档位价
        // 6. 查询当天是否已通知过，未通知则推送
        // 7. 写入 t_stock_price_alert
    }
}
```

#### WeChatNotifyService

```java
public interface WeChatNotifyService {
    /**
     * 发送档位到达通知
     * @param stockName    股票名称
     * @param stockCode    股票代码
     * @param direction    1-买入 2-卖出
     * @param levelNo      档位编号
     * @param triggerPrice 触发价
     * @param currentPrice 当前价
     * @param fixedShares  计划操作股数
     */
    boolean sendLevelAlert(String stockName, String stockCode, int direction,
                           int levelNo, BigDecimal triggerPrice,
                           BigDecimal currentPrice, int fixedShares);
}
```

### 6.3 定时任务配置

```java
@Configuration
@EnableScheduling
public class ScheduledTaskConfig {
}
```

- Cron: `0 */1 9-15 * * MON-FRI`（周一至周五 9:00-15:59，每分钟一次）
- 实际执行时判断 `LocalTime.now()` 是否在交易时段内：
  - 上午：9:30 — 11:30
  - 下午：13:00 — 15:00
  - 午休 11:30-13:00 和盘前盘后跳过
